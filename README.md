# Patipatra – Wedding Planning Website 💍

Patipatra is a wedding planning website designed to help families, brides, and grooms explore wedding services and select the arrangements they need for their special day.

The website provides a simple and user-friendly interface where users can browse available services, select multiple options, and submit a booking request without making any online payment.

## ✨ Features

* **User-Friendly Interface:** Clean and easy-to-navigate website.
* **Wedding Services:** Explore different wedding-related services and arrangements.
* **Multiple Selections:** Choose multiple services according to your preferences.
* **Booking Requests:** Submit selected services through a booking form.
* **Booking Confirmation:** Receive a confirmation message after submitting a request.
* **Admin Integration:** Connect with the backend to support booking management.
* **Responsive Design:** Designed to provide a convenient browsing experience across devices.

## 🚀 Getting Started

Follow these steps to run the frontend locally.

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm
* Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_FRONTEND_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd YOUR_FRONTEND_FOLDER
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🔗 Backend Integration

The frontend communicates with the Patipatra backend to handle booking-related operations.

The backend supports the booking workflow and provides a separate admin interface for managing booking requests.

Replace the repository URL and configure the appropriate backend API URL if you want to run the project locally.

## 💳 Payment Policy

Patipatra does not require customers to make direct online payments through the website. Customers can select their preferred services and submit a booking request, allowing further arrangements to be discussed according to their requirements.

## 🎯 Project Objective

The objective of Patipatra is to simplify the wedding planning process by bringing service selection and booking requests into one convenient online platform.
